# クラウド保存（GAS）の準備

旅程プランナーの旅程を、自分の Google ドライブにも保存するための準備です。最初に1回だけ行います（10分ほど）。

## 1. GAS のプロジェクトを作る

1. https://script.google.com/ を開き、左上の「新しいプロジェクト」を押す
2. 左上の「無題のプロジェクト」を押して、名前を「旅程プランナー保存」にする
3. 最初から入っている `function myFunction() { … }` をすべて消し、このフォルダの `コード.gs` の中身をすべて貼り付ける
4. 上の保存ボタン（フロッピーの絵）を押す

## 2. ウェブアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」
2. 「種類の選択」の歯車 →「ウェブアプリ」
3. 次のように選ぶ
   - 説明：旅程プランナー
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」を押す
5. 「アクセスを承認」が出たら、自分の Google アカウントを選ぶ
   - 「このアプリは Google で確認されていません」と出たら、「詳細」→「旅程プランナー保存（安全ではないページ）に移動」→「許可」
   - 自分で作ったものなので問題ありません（ドライブに「旅程プランナー」フォルダを作って読み書きする許可です）
6. 出てきた「ウェブアプリ」の URL（`https://script.google.com/macros/s/……/exec`）をコピーする

## 3. 旅程プランナーにつなぐ

1. PC の旅程プランナーで、右上の設定（つまみの絵）→「クラウドに保存」
2. 2-6 の URL を貼り、合言葉を決めて入れる（8文字以上）
3. 「つないで保存する」を押す。「保存済み」と出れば完了

**合言葉は必ずメモしてください。** Cookie を消したあとに旅程を戻すときに要ります（URL と合言葉の両方が要ります。URL もメモしておくと安心です）。

## スマホも同じクラウドにつなぐとき

PC の設定の「スマホにも設定」で出るリンク（または QR コード）を、スマホで開きます。
ホーム画面に追加したアプリで使うときは、アプリの設定の「クラウドに保存」で、同じ URL と合言葉を入れてください（Safari とホーム画面のアプリは保存場所が別のため）。

## うまくいかないとき

| 出てくる文 | 直し方 |
|---|---|
| URL が見つかりませんでした | URL が途中で切れていないか確かめて、2-6 からもう一度コピーする |
| アクセスを断られました／つながりませんでした（電波はある） | 「デプロイ」→「デプロイを管理」→ 鉛筆の絵 →「アクセスできるユーザー」を**「全員」**（「Google アカウントを持つ全員」ではない）にして「デプロイ」。URL は変わらない |
| GAS のウェブアプリの URL ではないようです | 「…/exec」で終わる URL を使う（エディタのアドレスバーの URL ではない） |

## コード.gs を直したとき

「デプロイ」→「デプロイを管理」→ 鉛筆の絵 →「バージョン」を「新バージョン」→「デプロイ」。URL は変わりません。

## ドライブに置かれるもの

「旅程プランナー」フォルダに、次のファイルができます。

- `trip_<ハッシュ>.json`：いまの旅程（合言葉から作ったハッシュが名前に入る。合言葉そのものは保存しない）
- `trip_<ハッシュ>_<日付>.json`：その日に最初に上書きする前の版（30日ぶん）。まちがえて上書きしたときは、このファイルの中身を使って戻せます
